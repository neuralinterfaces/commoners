# Commoners Examples
This subfolder includes various examples and demos showcasing the capabilities of Commoners.

To run any example, you can use the Commoners CLI. For instance, to run the demo application, execute:
```bash
commoners examples/demo
```

## Examples
### [Comprehensive Demo](./examples/demo)
The `examples/demo` directory contains a comprehensive demo application for Commoners. All end-to-end tests are run against this demo, ensuring it serves as a reliable reference for the tool's capabilities.
